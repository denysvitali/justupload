Temporary file sharing. One download, then it is gone.

Drop a file here or click to pick one · max 10 MB

curl

curl -T file.txt {{BASE}}/
curl -F 'file=@file.txt' {{BASE}}/

wget

wget --method=PUT --body-file=file.txt -qO- {{BASE}}/

Rules

  • 10 MB max per file
  • deleted after the first download
  • deleted after 1 hour
  • 30 MB of uploads per hour per IP
  • no backups, no guarantees
